
# Machine Learning Algorithm Collections

A collection of Machine Learning and Deep Learning projects implemented while learning and experimenting with different AI concepts, algorithms, and frameworks.

The goal of this repository is to document my learning journey through practical implementations ranging from classical Machine Learning algorithms to modern Deep Learning architectures.

## Contents

### Machine Learning

#### K-Nearest Neighbors (KNN)

* Classification using the Iris dataset
* Feature-based prediction and evaluation
* Comparison of different values of *k*

#### KNN Regression

* House price prediction using the California Housing dataset
* Mean Squared Error (MSE) evaluation
* Distance-based regression techniques

#### Data Scaling and Preprocessing

* Min-Max Scaling
* Euclidean vs Manhattan distance comparison
* Impact of feature normalization on KNN performance

#### Gradient Descent

* Implementation and experimentation with optimization techniques
* Understanding how machine learning models learn parameters

#### Vectorized NumPy Operations

* Performance comparison between loop-based and vectorized implementations
* Efficient computation of Euclidean distances

### Deep Learning

#### Deep Neural Networks

* Multi-layer neural network experiments
* Forward propagation concepts
* Parameter initialization and matrix operations

#### Convolutional Neural Networks (CNNs)

* Image processing and classification experiments
* Introduction to convolutional layers and feature extraction

#### Support Vector Machines (SVMs)

* Binary and multi-class classification
* Margin maximization concepts

### Natural Language Processing

#### Mini Question Answering Machine

* Experimental NLP project
* Early exploration of question-answering systems
